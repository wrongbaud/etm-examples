# etm-examples

Reference materials for the following blog post: https://voidstarsec.com/blog/arm-tracing-etm-itm

# Contents

- `example-traces`: Contains an example ETM trace to load into pulseview
- `openocd-configs`: Example OpenOCD configs for enabling ETM traces on STM32 series MCUs
- `scripts`: Python scripts for enabling ETM via OpenOCD and example flash patching scripts
